DESCRIPTION DU PROJET
Ce projet modélise une campagne de communication ou de diffusion d’information dans un réseau social représenté par un graphe aléatoire.
Objectif global :
    Simuler la propagation d’un message à travers un réseau de contacts,
    en partant de différents types de sommets (influents ou périphériques),
    et mesurer combien de personnes (sommets) sont touchées après un certain nombre de jours. 
    Le dossier résentre des fichier correspondant à chaque question du devoir  . 

EXECUTION : 
Il suffit d'exécuter chaque script dans l'ordre des questions.
